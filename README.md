# DocSign

Русскоязычный прототип AI-помощника для анализа договоров. В проекте есть две версии интерфейса:
- **Десктоп** — боковая панель, таблицы дел, сплит-режим просмотра документа и AI-инсайты.
- **Мобильная** — компактный дашборд с картами, загрузкой и редактированием текста с подсветкой рисков.

Поддерживаемые форматы загрузки: **PDF, DOCX, TXT**. Текст распознаётся на клиенте (pdf.js, mammoth), риски подсвечиваются и можно автоматически заменить проблемные фрагменты.

Для запуска трёхэтапного AI-пайплайна (Parser → Red Team → Judge) добавьте API ключ через кнопку «API ключ» в интерфейсе. Если ключ не задан или анализ завершился ошибкой, на экране появится понятное сообщение с подсказкой.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из консоли в браузере. Переключение между десктопной и мобильной версиями доступно из интерфейса (кнопка в хедере/сайдбаре). Светлая/тёмная тема включается тем же переключателем.

### Быстрый сценарий
1. Нажмите «Анализ документа» (мобильный) или баннер/кнопку «Новое дело» (десктоп), выберите PDF/DOCX/TXT.
2. После чтения файла откройте «Редактировать», чтобы заменить текст по рекомендациям или сохранить как есть.
3. На десктопе изменения отображаются в сплит-режиме AI-анализа; на мобильном добавляются в «Последние дела».
