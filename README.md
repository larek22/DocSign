# DocSign

Веб-приложение на React для работы с юридическими документами: редактор с режимом правок и встроенная панель рукописной подписи.

## Запуск

```bash
npm install
npm run dev
```

Откройте показанный адрес (обычно http://localhost:5173) в браузере.

## Сборка

```bash
npm run build
```

## Возможности
- Визуальный юридический редактор с режимом отслеживания правок.
- Вставка таблиц, изображений, разрывов страниц и подписей через меню «Вставить».
- Импорт документов в форматах **DOCX**, **HTML**, **TXT** (автоочистка старых подписей при загрузке нового файла).
- Экспорт в **HTML**, **DOCX** и **PDF** с сохранением расстановки подписей.
- Подписи добавляются как интерактивные стикеры, которые можно свободно перемещать и масштабировать.
