# DocSign

Русскоязычный прототип AI-помощника для анализа договоров. В проекте есть две версии интерфейса:
- **Десктоп** — боковая панель, таблицы дел, сплит-режим просмотра документа и AI-инсайты.
- **Мобильная** — компактный дашборд с картами, загрузкой и редактированием текста с подсветкой рисков.

Поддерживаемые форматы загрузки: **PDF, DOCX, TXT**. Текст извлекается локально (pdf.js, mammoth), затем отправляется на серверный анализ.

Для запуска многошагового AI-пайплайна (Extract → Chunk → Analyze → Judge/Repair) используется серверный endpoint `/api/analyze` (Node/Express). Клиент не обращается к OpenAI напрямую: ключ можно указать в интерфейсе (отправляется в заголовке `x-openai-key`) либо задать переменную окружения `OPENAI_API_KEY` для сервера. Если ключ отсутствует или анализ завершился ошибкой, в UI появится сообщение с подсказкой и кнопка повторить.

## Запуск

```bash
npm install
# запуск серверного API
npm run dev:server
# в отдельном окне — фронтенд с прокси на /api
npm run dev
```

Откройте адрес из консоли в браузере. Переключение между десктопной и мобильной версиями доступно из интерфейса (кнопка в хедере/сайдбаре). Светлая/тёмная тема включается тем же переключателем. Для теста API без UI можно выполнить:

```bash
curl -X POST http://localhost:3001/api/analyze \
  -H "Content-Type: application/json" \
  -H "x-openai-key: $OPENAI_API_KEY" \
  -d '{
    "text": "ДОГОВОР...",
    "options": {"model": "gpt-5-mini", "maxTokens": 1600, "topP": 1}
  }'
```

### Быстрый сценарий
1. Нажмите «Анализ документа» (мобильный) или баннер/кнопку «Новое дело» (десктоп), выберите PDF/DOCX/TXT.
2. После чтения файла откройте «Редактировать», чтобы заменить текст по рекомендациям или сохранить как есть.
3. На десктопе изменения отображаются в сплит-режиме AI-анализа; на мобильном добавляются в «Последние дела».
