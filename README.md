# DocSign

Веб-приложение на React/TypeScript для работы с юридическими документами: редактор на TipTap с режимом правок и встроенная панель рукописной подписи.

## Запуск

```bash
npm install
npm run dev
```

Откройте показанный адрес (обычно http://localhost:5173) в браузере.

## Сборка

```bash
npm run build
```

## Серверная конвертация (Pandoc + PyMuPDF)

Фронтенд ожидает, что эндпоинт `/api/convert-file` примет `multipart/form-data` с полем `file` и вернёт JSON вида
`{ html?: string; tiptap?: object; plainText?: string; warnings?: string[]; engine?: string }`.

- Для **DOCX/ODT/RTF/MD/TXT** рекомендуемый движок — `pandoc`.
- Для **PDF** фронтенд указывает `engine=pymupdf-bbox` и передаёт параметры `stripLeftMarginPx=48`,
  `stripHeaderPx=64`, `stripFooterPx=60` — их нужно использовать, чтобы отбрасывать колонтитулы и номера строк.
- При возврате HTML важно заменить локальные пути картинок на публичные URL и санитизировать содержимое.
- Если у файла нет текстового слоя, сервер должен выполнить OCR и вернуть предупреждение в `warnings`.

## Возможности
- Визуальный юридический редактор на TipTap (структурированная модель, устойчивое форматирование и заголовки) на строгом TypeScript.
- Вставка таблиц, изображений, разрывов страниц и подписей через меню «Вставить» (таблицы резайзятся, изображения масштабируются по ширине контейнера).
- Импорт документов через серверную конвертацию (Pandoc/ocr-сервис с PyMuPDF для PDF) в форматах **DOCX**, **ODT**, **RTF**, **HTML**, **TXT**, **MD/Markdown** и **PDF**: фронтенд отправляет файл на `/api/convert-file`, передаёт желаемый движок (`pandoc` или `pymupdf-bbox` + параметры обрезки полей), отображает прогресс и очищает старые подписи после успешной загрузки.
- Экспорт в **HTML**, **DOCX** и **PDF** с сохранением расстановки подписей.
- Подписи добавляются как интерактивные прозрачные стикеры, которые можно свободно перемещать и масштабировать внутри страницы, drag/resize плавно обрабатываются через rAF и прямое обновление стилей.
